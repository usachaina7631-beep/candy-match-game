# 🍬 Candy Dhamaka — Free Candy Match 3 Game

Play free online: https://usachaina7631-beep.github.io/candy-match-game/

A match-3 candy puzzle game that runs fully in the browser — no download, no sign-up.

- 8×8 board, 6 candy types
- 100 levels with score targets and move limits
- Special candies: Striped (match 4), Wrapped (L/T), Colour Bomb (match 5)
- Boosters: Lollipop Hammer, Shuffle, Free Swap, +5 Moves
- Candy Shop, Daily Reward, progress saved on your device
- Keyboard controls supported
